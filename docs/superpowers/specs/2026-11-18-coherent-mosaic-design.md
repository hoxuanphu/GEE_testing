# Ghép cảnh tương đồng và mask mây Mosaic ổn định

User requested implementation after reviewing the near-date proposal, plus cloud-masked/unmasked stable mosaics. Existing branch and all unrelated edits must remain; no commit/push.

- Optional `scene_grouping=any|near_date|same_pass`, default `any` for compatibility. UI opt-in; near_date defaults to 3 days with 1/3/5/7-day controls. The maximum span applies to the entire set; never silently expand it. same_pass groups S2 by datatake and spacecraft; Landsat by spacecraft/path/UTC acquisition day, allowing adjacent rows. Missing required grouping metadata does not imply compatibility.
- Supported on optical RAW and stable mosaic, including point/rectangle merges and province/commune/vector. Existing single scenes, other composites and time series stay unchanged.
- Candidate groups prefer >=99% geometric ROI coverage, same acquisition pass, short span, matching platform/orbit and similar illumination/view geometry, with cloud metadata as a secondary quality estimate. Angular differences wrap correctly; missing angle metadata incurs a penalty, not a fabricated zero difference. Do not require identical MGRS tile or WRS row. Conditions are preferences, with hard product/platform/user filters retained.
- Metadata candidates bounded at 400; fail clearly rather than silently truncate. Shortlist at most 5 distinct groups and evaluate at most 3 pixel-coverage candidates. Group ranking uses clipped footprint unions, not summed intersecting areas. When grouping is enabled, final unmasked spectral coverage must meet 99%; cloud masking can reduce final valid coverage. With grouping disabled, stable mosaic retains legacy partial-coverage behavior and reports actual coverage. Explain insufficient coverage without relaxing the day window. No new broad per-pixel QA scoring across every scene.
- `mosaic_mask_clouds: bool=True` applies only to stable mosaic. True: original per-scene SCL/QA masks before mosaic. False: keep cloudy values. Always exactly one selected scene per tile/path-row, unlike RAW gap filling across dates. Scene selection must be identical between mask modes. Preserve valid zero and NoData. This is independent of near-date grouping and RAW color balance.
- Freeze preview/export source selection for new modes. Include grouping report and mask policy in request/response/download URLs, existing snapshots and final TIFF tags. Keep existing resumable download semantics and reject changed options on token-bound download.
- UI presents method selection for enabled point/rectangle merges as well as admin/vector; hide unsupported median/medoid/base-score choices in point/rectangle. Controls disappear for unrelated datasets and time series; changes invalidate old results.
- Report UTC source times, pass/platform/orbit/angle metadata where present, whole-group span, data/output coverage, shortlist limits and missing metadata. Synthetic/offline verification does not establish real-scene color quality.
